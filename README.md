# COHONDUCAFE GROUP — Sitio Web

Rediseño con **Astro + Tailwind CSS**.

## Instalación

Desde esta carpeta en tu terminal:

```bash
npm install
```

## Desarrollo (con servidor local)

```bash
npm run dev
```
Abre http://localhost:4321

## Build para XAMPP

```bash
npm run build
```
Esto genera la carpeta `dist/`. Copia su contenido a tu carpeta XAMPP para servir el sitio estático.

## Páginas

- `/` — Inicio
- `/nosotros` — Historia y valores
- `/marcas` — HOSCO, Tostadora HC, Mina Honda, Fundación COH, Bosques COH
- `/contacto` — Formulario de contacto
